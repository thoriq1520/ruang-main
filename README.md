# Mini Games Coop

Koleksi mini game P2P sementara berbasis Vite, TypeScript, dan Trystero. Kota Raya dan Panic Crew tersedia dalam satu aplikasi.

```bash
npm install
npm run dev
```

Tidak ada akun, backend aplikasi, atau database permanen. Papan, kartu, pion, rumah, dan hotel Kota Raya saat ini dibuat dengan CSS.

- Aturan game pertama: `PRD.md`
- Aturan game kedua, Panic Crew: `PRD-PANIC-CREW.md`
